# Readora

A book discovery app built with React Native (CLI) and TypeScript.
Search books from Open Library, save favourites and manage your reading list.

> Status: work in progress (IN3210 Assignment 2)

## Tech stack
React Native CLI, TypeScript, React Navigation, Redux Toolkit,
DummyJSON (auth), Open Library API (books)

## Getting started
1. Complete the React Native environment setup (Android).
2. `npm install`
3. `npm start`
4. In another terminal: `npm run android`
